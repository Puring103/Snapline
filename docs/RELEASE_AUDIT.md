# 发布需求审计

审计日期：2026-08-01。当前交付范围是自部署服务端与 Windows 桌面端；Android 按本阶段约定排除。

| 需求 | 状态 | 验收结果 |
| --- | --- | --- |
| 文本、截图、录音、图片、视频采集 | 完成 | 原生截图与录音、粘贴图片、图片/视频导入均直接加密落盘 |
| 完整 Markdown 与自动保存 | 完成 | CodeMirror 6 完整编辑器；快捷窗口使用轻量编辑器；无保存按钮 |
| 快速入口与全局快捷键 | 完成 | 独立记录窗口；文本、截图、录音快捷键与单窗口复用通过测试 |
| 快速入口仅显示记录界面 | 完成 | 不显示历史、AI、搜索、设置或侧栏 |
| 历史记录 | 完成 | 搜索、分页、跳转、收藏、归档、删除和组合筛选 |
| 特殊标记与 `账目` | 完成 | 通用自定义标记；`账目` 只是内置标记，无记账子系统 |
| 强制登录与设备管理 | 完成 | 无游客状态；注册、登录、令牌轮换、设备列表与撤销 |
| 本地与服务端加密 | 完成 | XChaCha20-Poly1305、UMK/DEK、加密附件分块；服务端只持有密文 |
| PostgreSQL 与 myServer | 完成 | PostgreSQL 17 内部网络；API 部署到 SSH Host `myserver`，仅回环绑定 `58080` 并经 Caddy 暴露 |
| 跨设备云同步 | 完成 | durable outbox、pull/ack、幂等 push、冲突处理、附件续传与真实双设备测试 |
| 单模型多模态元数据 | 完成 | 用户填写一个 OpenAI 兼容 Base URL、API Key 和模型；未配置时不索引 |
| 无 Embedding Agent 搜索 | 完成 | 内存 FTS5、结构化过滤、七个只读工具、多轮限制和真实引用；无向量数据库 |
| AI Key 安全 | 完成 | 仅存 Windows Credential Manager，客户端直连 AI 服务，不进入 Snapline 服务端 |
| Rust 技术栈 | 完成 | Axum、SQLx、Tauri、Rust 加密与本地仓库；React 只负责桌面界面 |
| 测试与文档 | 完成 | 前端 27 项、Rust 43 项、真实媒体/服务器测试、Release 构建；功能、安全、自部署和测试文档持续维护 |
| Git 模块提交 | 完成 | M0-M11 分模块实现、测试、文档化并独立提交 |
| Android | 本阶段排除 | 未实现，不计入 Windows/服务端里程碑完成条件 |
| 正式公网 HTTPS | 待外部条件 | 当前 `http://122.51.119.75/snapline/` 仅供开发验收；需要域名、DNS 与可信证书后才能使用真实长期账号和内容 |

## 发布结论

Windows 桌面端与 `myserver` 服务端在当前范围内功能闭环，Release 可执行文件构建成功。正式生产上线仍以 HTTPS 为硬门槛；端到端内容加密不能保护明文 HTTP 中的密码、Access Token 和 Refresh Token。
